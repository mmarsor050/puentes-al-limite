# [Puentes al límite](https://mmarsor050.github.io/puentes-al-limite/puentes-al-limite.html)

Juego de construcción de puentes con física real para Tecnología y Digitalización (2.º y 3.º ESO, válido para otros cursos). Trabaja cargas, triangulación, tracción y compresión, apoyos, arcos, cables, coeficiente de seguridad, flexión y tipos de puente. Incluye un Taller de esfuerzos. En español y en inglés.

## Cómo se usa en el centro

1. Descarga `puentes-al-limite.html` y cópialo en los ordenadores (escritorio, carpeta compartida, USB o Classroom), o comparte el enlace de arriba.
2. Ábrelo con doble clic. Funciona en Chrome, Edge y Firefox **sin conexión a internet** y sin instalar nada.
3. Cada alumno crea su perfil: alias, curso, grupo y avatar, con PIN opcional. No se piden datos personales.

### Dónde se guardan los datos

- El progreso se guarda **en el navegador de ese ordenador**. No se envía nada a internet.
- En un mismo ordenador puede haber varios perfiles, por ejemplo para varios grupos que comparten el aula.
- Si se borran los datos del navegador, o el ordenador se restaura al apagarse (equipos «congelados»), el progreso se pierde. Para eso está **Guardar partida**.

### Guardar y recuperar partida (cambiar de ordenador)

- **Guardar partida** (menú o barra de cada obra):
  - **Descargar archivo:** un `.txt` para guardar en el Drive del centro o en un USB.
  - **Copiar código:** unos 300-500 caracteres para pegar en Classroom o en un correo.
- **Recuperar partida** (pantalla de inicio): se elige el archivo o se pega el código.
- La partida incluye perfil, notas, insignias, Taller y los puentes a medio construir.

### Evaluación

- **Nota por obra (sobre 10):** cruza dentro del presupuesto (+7), sin roturas (+2) y pregunta final acertada a la primera (+1).
- **Taller de esfuerzos:** test de 10 situaciones y ejercicio «Señala en el puente» con 3 puentes de 6 barras.
- **Perfil del alumno:** nota global, notas del Taller y 16 insignias, y un «Resumen para el profesor» para copiar con todas las notas.

## Para el profesorado

Las obras se desbloquean en orden. El botón **Profesor**, al pie del menú, las abre todas en ese ordenador con un código.

Existe además una **app del profesor** (soluciones de referencia de las 10 obras y rúbrica digital que calcula la nota por criterio a partir de los códigos de partida del alumnado). No se publica, para que el alumnado no tenga las soluciones. Si eres docente y quieres usarla, pídesela al autor: te pasará el archivo y el código del botón Profesor.
